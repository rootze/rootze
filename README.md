## Current Work

### COMPACT

**COMPACT** is an in silico gene-module perturbation framework for predicting how targeted interventions reshape cellular states and gene-regulatory networks.

The project focuses on:

- Predicting transcriptome-wide responses to gene-module perturbations
- Modeling transitions between cellular states
- Identifying candidate therapeutic interventions
- Evaluating perturbation effects using regulatory networks and multi-omic evidence
- Generating biologically interpretable and experimentally testable hypotheses

### Pharmacogenomics Project — CABS

During **Summer 2026**, I am working with **CABS** on a pharmacogenomics project focused on applying genomic, clinical, and computational approaches to drug-response analysis and therapeutic discovery.

### Operon

I contribute to **Operon**, an AI-powered bioinformatics desktop platform that pairs Claude with published computational workflows.

Operon supports:

- Single-cell RNA-seq
- Bulk RNA-seq
- ATAC-seq
- GWAS
- Proteomics
- AI-assisted workflow planning
- Scientific literature analysis
- Automated report generation
- Local and HPC deployment

### hdWGCNA

I am a core contributor to **hdWGCNA**, an open-source R package for gene co-expression network analysis in high-dimensional transcriptomic data.

My work includes:

- Gene co-expression network construction
- Module identification
- Eigengene analysis
- Hub-gene prioritization
- Cross-dataset network comparison
- Documentation and reproducible analysis workflows
